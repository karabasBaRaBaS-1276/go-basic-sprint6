### Назначение модуля
Конвертер азбуки Морзе

### Структура проекта
Проект состоит из следующих пакетов, не считая основного (main): 

1. Пакет **server**. Здесь создается новый сервер, http-роутер и регистрируются хендлеры.  
2. Пакет **handlers**. В пакете handlers два хендлера:
    * первый для отправки файла с формой HTML index.html;
    * второй для загрузки файла с данными из этой формы и передачи на обработку в пакет _service_.
3. Пакет **service**. Здесь автоматически определяется, в каком виде (текст или код Морзе) пришли данные из файла и с помощью пакета _morse_ производится конвертация.
4. Пакет **morse**. Этот пакет используется для конвертации кода Морзе в текст и обратно. Для этого есть две функции:
    * Функция `ToText(morse string) string`, которая принимает и возвращает строку. Эта функция конвертирует код Морзе в текст.
    * Функция `ToMorse(text string) string`, которая так же принимает и возвращает строку и конвертирует текст в код Морзе.
